# Obsidian をもう1つ増やす（アカウントを分けて使う）

Obsidian を **2つ並べて、それぞれ別のアカウントでログインした状態** で使えるようにするツールです。
タスクバーに2つ並び、アイコンの色で見分けられます。

すでに Obsidian を使っている人向けです。Obsidian が入っていない場合は、先に公式サイトからインストールしてください。

## 使い方（2通り）

- **自分で入れる** → 下の「手で入れる場合」
- **Claude Code にやらせる** → このリポジトリのURLと一緒に、下の文をそのまま貼る

```
Windowsのこのツールで、Obsidianをもう1つ増やして別アカウントで使えるようにしてほしい。
https://github.com/tomita-anri/obsidian-multi-profile

リポジトリを取得したら SETUP-FOR-CLAUDE.md を読んで、その通りに進めて。
名前は「Obsidian（〇〇）」、IDは「〇〇」、アイコンの色は〇〇でお願い。
最後に、私が手でやる必要のある操作だけ教えて。
```

## 手で入れる場合

1. ZIPを**展開してから**、フォルダごとデスクトップなどに置く（ZIPの中から直接実行しない）
2. `start-here.bat` をダブルクリック
   - 「Windows によって PC が保護されました」と出たら、**詳細情報 → 実行** を押す
     （ネットから受け取ったファイルに出る警告です）
3. 聞かれるものに答える（Enterだけでも進みます）
   - 2つ目のObsidianの名前（例: `Obsidian（AI推進部）`）
   - フォルダにつける英数字のID（例: `ai`）
   - アイコンの色（1:オレンジ / 2:水色 / 3:グリーン / 4:レッド）
4. 「完了しました」と出たら、スタートメニューで付けた名前を探して
   **右クリック →「タスクバーにピン留めする」**
5. 起動して、2つ目のアカウントでログインする

ピン留めだけは自動でできません（Windowsの仕様）。

## 何が起きるか

| | 置き場所 |
|---|---|
| 元の Obsidian（触りません） | そのまま |
| 2つ目の本体 | `%LOCALAPPDATA%\Obsidian-<ID>` |
| 2つ目の設定・ログイン情報 | `%APPDATA%\obsidian-<ID>` |
| 2つ目のアイコン | `%APPDATA%\obsidian-<ID>\obsidian-icon.ico` |
| ショートカット | スタートメニュー |

**仕組み**：Obsidian は起動オプション `--user-data-dir` で設定フォルダを切り替えられます。
設定フォルダが別なら、ログインしているアカウントも保管庫リストも完全に別になります。
本体フォルダも複製するのは、Windows が **exeの置き場所でタスクバーのボタンを分ける** ためです（同じexeだと1つのボタンにまとまってしまう）。

## `obsidian://` リンクを使っている人は、これも読んで

ダッシュボード・タスク管理ツール・他のノートアプリなどから `obsidian://` で始まるリンクでObsidianを開いている場合、**2つ目を入れると、そのリンクが効かなくなることがあります。**

**症状**：リンクを踏むと**タスクバーのアイコンが点滅するだけで、窓が前に出てこない**。

**理由**：Obsidianは起動のたびに「`obsidian://` は自分が処理する」とWindowsに登録し直します。このとき**設定フォルダの指定（`--user-data-dir`）は付きません**。2つ目のObsidianがこの登録を取ると、リンクを踏んだときに「2つ目のexeを、1つ目のアカウントの設定で」起動してしまい、狙った窓を前に出せません。**1つ目のアカウント側の保管庫リストが書き換わることもあります。**

**直しかた**：`fix-links.bat` をダブルクリックして、どちらのObsidianにリンクを処理させるか選ぶ。

- `1`（既定）… 元から入っているObsidian。**2つ目を入れる前と同じ状態に戻る**
- `2` … 2つ目のObsidian。設定フォルダの指定を付けて正しく登録する。IDを聞かれます

管理者権限は不要（自分のユーザー領域だけ触ります）。

**Obsidianは起動のたびにこの登録を書き戻すので、これは一度きりの対処ではありません。** リンクが効かなくなったら、また押してください。

## 注意

- **同じ保管庫を2つのウィンドウで同時に開かないでください。** Obsidian は同時編集を想定していません
- 2つ目は本体を複製したものなので、**Obsidian本体をアップデートしても自動では新しくなりません**。
  アップデートしたら `start-here.bat` をもう一度実行してください（設定・ログインは消えません）
- ディスクを 300MB ほど使います
- アイコンは exe には手を加えず、ショートカット側に当てています。
  exe に埋め込む方法だと署名が壊れ、Smart App Control が有効なPCで起動できなくなるためです

## うまくいかないとき

同じフォルダにできる `setup-log.txt` を送ってください。実行内容がすべて記録されています。
